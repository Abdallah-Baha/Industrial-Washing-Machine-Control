# Industrial Washing Machine Control System

Industrial washing machine control system designed using EPLAN Electric P8.

## Features
- Forward /Reverse motor control
- Water level control
- Sequential operation using timers
- Heating system control
- Motor protection system

## Protection Components
- RCCB
- Overload Relay
- Phase Monitoring Relay

- Power Circuit
- Control Circuit
- Project PDF
